# 更新版デザインと実装の差分表（2026-11-22）

対象: `design/` の更新版 11 枚（06, 08, 09, 10, 11, 12, 14, 16, 21, 23, 24）と `SPEC.md` §8。
作成時点のコードは `f92828d`（feature/installer）。デザインの文字・ボタン・トグル・選択状態を HTML から取り出し、実装（`crates/app/src/ui/*`・`toast.rs`・`updater.rs`・`crates/shell-ext/src/menu.rs`・`crates/core/src/settings.rs`）と突き合わせた。

判定:
- **実装済み**: デザインどおり（文言・状態・操作が一致）
- **未実装**: デザインと違う、または無い → 今回実装する
- **仕様と矛盾**: デザインのとおりにすると既存の決定・仕様・プラットフォームの制約とぶつかる → 実装せず `QUESTIONS.md` に記録

## SPEC §8 との照合

§8 の各行（動画の自動アップロード、通知タブ、右クリックメニュー・SteamVR トグル、更新を確認、アンインストール、情報タブ、通知 3 種、最新です、手動の更新、403 の案内、403/503 の説明）はすべて上の表のどれかに対応し、矛盾は無い。
